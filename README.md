## Details

A deterministic program (pure Python 3 standard library) that writes
one one-liner about AI coding agents to `/output/entry.txt`:

> Every morning I onboard my AI agent like a new hire. Every morning, he is one.

The joke: an AI agent keeps no memory between sessions, so the daily
ritual of re-explaining the codebase and re-onboarding it is not like
its first day — it literally is, every single day. A truth every
developer who works beside an agent recognises at once.

Run: `python3 main.py` writes the joke to `/output/entry.txt`
(override the directory with `MAKEFUN_OUTPUT_DIR`). No dependencies,
no network, byte-identical on every run.
